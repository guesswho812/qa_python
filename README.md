# qa_python# Тесты для BooksCollector

## Реализованные тесты

### Метод add_new_book
- Добавление книг "Дюна" и "Основание"
- Нельзя добавить дубликат "Солярис"  
- Проверка валидации длины названия (0-40 символов)

### Метод set_book_genre
- Установка жанра "Фантастика" для "Нейроманта"
- Нельзя установить несуществующий жанр "Космоопера"

### Метод get_book_genre
- Получение жанра существующей книги
- Получение жанра несуществующей книги

### Метод get_books_with_specific_genre
- Поиск книг по жанру "Фантастика" ("Дюна")

### Метод get_books_for_children
- Фильтрация книг без возрастного рейтинга ("Хроники Нарнии")

### Метод add_book_in_favorites
- Добавление в избранное "451° по Фаренгейту"
- Нельзя добавить книгу в избранное дважды

### Метод delete_book_from_favorites
- Удаление из избранного "Война миров"

### Метод get_list_of_favorites_books
- Получение списка избранных книг

## Запуск тестов
```bash
pytest tests.py -v
